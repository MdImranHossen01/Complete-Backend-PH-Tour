# Setup project & Github

- Create a folder for the project and rename. 
- Open In Vs Code
- In terminal write `git init`
![git init](image.png)
- Create `.gitignore` file in project folder

```javascript 
node_modules
```

- type `git checkout -b development` in terminal to switch development branch
